# 사진 미보유 관광지 외부 이미지 검증

검증일: 2026-09-15

## 목적과 범위

- 대상: 활성 관광지 3,885건 중 대표 이미지와 상세 이미지가 모두 없는 202건
- 이 문서는 외부 이미지를 DB에 넣기 전 장소 일치 여부와 이용 조건을 검증하기 위한 기록이다.
- 검증이 끝나기 전에는 `tourist_spot` 및 `tourist_spot_image` 데이터를 변경하지 않는다.

## 웹 재탐색 및 실제 반영

사용자 요청에 따라 2026-09-15에 남은 137건을 네이버 이미지 검색으로 다시 탐색했다.
검색 결과 자체는 근거로 사용하지 않고 다음 조건을 모두 만족한 경우에만 채택했다.

- 원문 제목에 DB 관광지명이 포함됨
- 검색어에 DB 주소의 시·군·구를 포함함
- 한국관광공사 이미지 서버 또는 지자체·공공기관·대학 등 공식 원문에서 제공됨
- 원본 URL이 실제 GET 요청에서 이미지 MIME 타입과 HTTP 200/206을 반환함
- 서로 다른 관광지에 동일한 이미지 URL이 중복 배정되지 않음

재탐색 결과 70건을 추가 채택했다. 한국관광공사 이미지 서버가 57건이고,
지자체·공공기관 등 공식 웹 원문이 13건이다. 원문 제목이 비어 장소 일치를 확인할 수
없었던 `하의도 토지항쟁비` 후보 1건은 오탐으로 제외했다. 상세 결과는
`backend/docs/missing-image-web-discovery.csv`에 기록했다.

기존 승인 61건과 재탐색 승인 70건, 총 131건은
`db/danyeogam_external_images.sql`로 반영한다. 이 SQL은 대표·썸네일 URL과 상세 이미지,
출처 기관, 원문 페이지, 라이선스, 표시 문구, 검증일을 함께 저장하며 재실행해도 같은
검증 이미지 행을 중복 삽입하지 않는다. `scripts/import-local-seed.ps1`은 기본 시드 뒤에
이 파일을 자동 적용한다.

반영 후 완전 무사진 관광지는 71곳이다. 구성은 웹 재탐색에서도 신뢰 가능한 후보를 찾지
못한 67곳과 이용 조건이 제한 유형이라 자동 사용하지 않은 국가유산청 후보 4곳이다.

## 채택 기준

1. 장소명과 주소 또는 관리기관 정보가 DB의 관광지와 일치해야 한다.
2. 지자체, 국가기관, 관광공사, 해당 시설의 공식 사이트를 우선한다.
3. 공공누리 제1유형 또는 상업적 이용과 변경이 가능한 동등한 라이선스를 우선 채택한다.
4. 공공누리 제2~4유형은 공모전 이후 서비스 운영 방식과 이미지 가공 여부가 확정될 때까지 조건부로 둔다.
5. 공식 페이지라도 이용 조건이 표시되지 않으면 사용하지 않는다.
6. 검색 결과, 블로그, 언론사, 숙박·여행 중개 사이트의 이미지는 권리 확인 없이 사용하지 않는다.
7. 후보 URL은 실제 GET 요청에서 HTTP 200과 이미지 MIME 타입을 반환해야 한다.
8. 외부 사이트의 화면용 URL을 그대로 핫링크하지 않고, 이용 조건이 허용하면 프로젝트가 관리하는 저장소에 보관한다.

## 현재 데이터 구조의 보완 필요 사항

`tourist_spot_image`에는 URL, 대체 텍스트, `copyright_type`, 원본 이미지 ID만 있고 다음 정보가 없다.

- 출처 기관명
- 출처 상세 페이지 URL
- 라이선스 이름과 라이선스 안내 URL
- 원본 파일을 확인한 날짜

또한 프론트 상세 화면은 이미지와 대체 텍스트만 렌더링하고 출처 문구를 표시하지 않는다. 외부 이미지를 추가하기 전에 위 메타데이터를 저장하고 상세 화면에서 출처·이용조건을 노출해야 한다.

## 후속 검증 순서

1. 국가유산에 해당하는 장소를 국가유산포털과 지자체 공공누리 자료에서 우선 대조한다.
2. 박물관·미술관·기념관은 시설 또는 지자체 공식 페이지에서 개별 사진 이용 조건을 확인한다.
3. 제1유형 또는 동등한 자유 이용 사진을 찾지 못한 장소는 기본 이미지 상태를 유지한다.
4. 전수 검증이 끝난 뒤 승인된 후보만 별도 데이터 마이그레이션으로 반영한다.
