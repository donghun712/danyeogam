## 제외 1,055건

| 사유 | 건수 | 처리 |

제외 건은 `sync_error`에 사유를 남기며, 좌표와 지역이 확인되기 전에는 지도나 GPS 스탬프 대상으로 제공하지 않는다.

## 이번 초기 덤프의 범위

전국 목록 응답의 이름, 주소, 유형, 지역, 좌표, 전화번호, 수정 시각과 대표 원본·썸네일 이미지를 적재했다. 관광지별 `detailCommon2` 설명과 `detailImage2` 추가 이미지 전체 수집은 약 9만 7천 회 이상의 추가 API 호출이 필요하므로 개발키 호출량을 보호하기 위해 이번 덤프에서는 실행하지 않았다. 상세 조회 API는 설명이 없을 때 안전하게 `null`을 반환하고 대표 이미지는 정상 제공한다.

추가 상세 데이터는 운영 호출 한도를 확인한 뒤 기존 해시·증분 동기화 구조로 채울 수 있다.

## 복원 검증

`db/danyeogam_schema.sql` 적용 후 `db/danyeogam_tour_seed.sql`을 별도 빈 DB에 복원했다. 복원 결과 지역 284건, 관광지 48,717건, `sx_tourist_spot_location` 공간 인덱스 1개를 확인했다. SQL 덤프에는 TourAPI·카카오 키가 포함되지 않는다.
