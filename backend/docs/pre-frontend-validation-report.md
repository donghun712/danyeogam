# 프론트 연결 전 백엔드 최종 검증 보고서

검증일은 2026-09-07이다. 사용자 DB와 분리한 MySQL 8.0.44, Java 17, Spring Boot 3.5.7 환경에서 실행했다.

## 결론

프론트 없이 검증할 수 있는 DB, API 계약, 세션, GPS 스탬프, 도감, 외부 API, 실행 패키지와 복원 절차가 정상 동작했다. 실제 TourAPI·카카오 및 MySQL 선택 테스트를 모두 활성화한 자동 테스트 87건이 통과했으며 실패, 오류, 제외는 0건이다.

서비스 카탈로그는 스탬프 목적에 맞춰 관광지(12)와 문화시설(14)만 제공한다. 행사·축제, 여행코스, 레포츠, 숙박, 쇼핑, 음식점은 현재 DB에서 제거했고 이후 동기화 요청에서도 제외한다.

## API와 외부 연동

- 헬스체크는 `UP`, Flyway 스키마 버전은 1로 확인됐다.
- 지역, 지도 bounds, 관광지 상세, 익명 세션, 도감, GPS 인증 API 통합 테스트가 통과했다.
- 서울 일부 bounds 실호출은 474개 마커를 반환했고, 경기도 도감은 1,963개 항목을 반환했다.
- 넓고 밀집된 지도 영역은 `BOUNDS_TOO_DENSE`로 차단되어 프론트가 지도를 확대하도록 유도한다.
- 실제 TourAPI 관광지 목록·상세 이미지와 카카오 주소 검색·역주소·주변 주차장 호출이 성공했다.
- 서버 압축, 세션 쿠키, GPS 멱등성과 동시 요청 제어를 자동 테스트로 확인했다.

로컬 단일 스모크 호출에서 경기도 도감 JSON은 349,265 bytes였다. 이는 운영 성능 보장 수치가 아니며, 서버는 2KB 이상 JSON에 gzip 압축을 적용한다. 프론트에서 광역 도감을 한 번에 표시하기 부담스러우면 연결 단계에서 페이지네이션 또는 시군구 단위 조회를 추가할 수 있다.

## DB 복원과 배포 준비

- 빈 DB에서 Flyway V1 적용 후 새 데이터 덤프 복원과 애플리케이션 재기동에 성공했다.
- 복원 후 지역 284건, 장소 15,335건, Flyway 성공 이력 1건, 공간 인덱스 1개를 확인했다.
- 모든 장소가 활성 스탬프 대상이며 허용 유형 외 데이터와 범위 밖 좌표는 각각 0건이다.
- 실행 가능한 Spring Boot JAR을 생성했다.
- 소스, 문서, DB 덤프에서 실제 API 키 일치 여부를 별도로 검사하며 실행 JAR에는 `.env`를 포함하지 않는다.

## 프론트 또는 운영 환경이 있어야 끝낼 수 있는 항목
