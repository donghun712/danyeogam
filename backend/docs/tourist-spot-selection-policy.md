# 관광지 선정 정책

## 확정 기준

스탬프 대상은 TourAPI `KorService2`의 현재 세부 분류 필드 `lclsSystm1/2/3`로 결정한다.

| 주제 | 코드 |
|---|---|
| 역사유적 | `HS/HS01/*` |
| 역사유물 | `HS/HS02/*` |
| 박물관 | `VE/VE07/VE070100` |
| 기념관 | `VE/VE07/VE070200` |
| 미술관·화랑 | `VE/VE07/VE070600` |

역사 분류는 `contentTypeId=12`만, 선정 문화 분류는 TourAPI가 반환할 수 있는 `contentTypeId=12`와 `14`를 모두 조회한다. 최종 판정은 유형과 세부 분류가 모두 일치해야 통과한다.

## 운영 원칙

- 선정 기준 밖 데이터는 자동 스탬프 대상이 아니다.
- 종교성지, 안보관광지, 행사, 축제, 코스, 레포츠, 숙박, 쇼핑, 음식점은 제외한다.
- 좌표가 유효하지 않으면 선정 분류라도 승격하지 않는다.
- 전국 전체 동기화가 완주했을 때만 기존 비선정 TourAPI 행을 비활성화한다.
- 지역 한정·페이지 제한 동기화는 전역 비활성화를 수행하지 않는다.
- 제외 행은 삭제하지 않아 정책 변경 시 재검토할 수 있다.

## GPS 현장 테스트 기준

현재 시작값은 인증 반경 100m, 허용 GPS 정확도 50m, 위치 측정 유효시간 2분이다. 경기전·전동성당처럼 경계가 넓거나 건물 밀집도가 높은 장소에서 실제 휴대폰으로 먼저 검증한 뒤 조정한다.
